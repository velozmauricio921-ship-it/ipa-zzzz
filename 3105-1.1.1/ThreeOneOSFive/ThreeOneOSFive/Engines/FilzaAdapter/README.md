# FilzaAdapter

This directory is an integration boundary, not a copy of Filza. `Sources/FilzaAdapter.swift` is a nonfunctional placeholder: it reports `notImplemented`, advertises no capabilities, and returns no files.

Only components that can be separated from Filza's host process, use permitted documented APIs, and pass license review may be considered later. No Theos target, dylib, tweak, entitlement, or external dependency is added to BAIJ STORE by this scaffolding.

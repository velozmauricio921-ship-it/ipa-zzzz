# Reserved Filza Source Area

This directory is reserved for source components considered in a future, separately reviewed integration. It is intentionally documentation-only and is not part of the Xcode Sources build phase.

No Filza or WQFiles code has been copied here. Before introducing any component, audit licensing/provenance, imports, frameworks, transitive dependencies, private APIs, hooks, entitlements, sandbox assumptions, filesystem/container access, native or kernel boundaries, OS availability, and concurrency behavior. Record the component-level decision and required adaptations in the integration plan before adding code.
